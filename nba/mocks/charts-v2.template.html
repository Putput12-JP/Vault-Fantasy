[mock] Vault NBA · shared chart kit

One chart kit for every page

shadcn's chart pattern (declare each series once, then one container, one tooltip, one legend), drawn in our own SVG on the Graphite look instead of recharts. Every chart gets the same header that reads the point in focus, the same dashed trace, the same legend, arrow-key stepping and the same motion. Real numbers from last season's Finals and the 2025-26 backtest.

The pieces

config
Each series once: label, color token, kind (bar, line, area, dot, reference line). Legends and tooltips read it, so a color never drifts between charts.
ChartCard
Title, a header that shows the point in focus (big mono number, context on the right), the plot, the legend, a footnote.
trace
The shared hover: dashed guide at the focused value with its number in a pill (horizontal for values, vertical for time). Rest state is the newest point.
axes + grid
One tick rule (nice steps), mono 10px labels, grid on the border tone.
keyboard
Tab to a chart, arrow keys step points, Home / End jump. Header is a live region.
